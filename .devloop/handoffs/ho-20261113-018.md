# 交付文档：图表 spec 与渲染管线（ChartSpec v1 + Plotly HTML/PNG artifact + agent_artifacts 落库）

> 开发会话 · initial · 2026-11-13T09:39:10.793Z

## 摘要

按 ADR-016 / ADR-008 与《接口冻结清单》§3/§5/§6 实现声明式图表管线，不引入 pydantic、v1 不执行任意 Python。新增 astock/agent/chart_spec.py（手写校验 + JSON Schema 白名单，未知字段/枚举/非白名单 transform op/超上限全部结构化报错，含 period 分钟档 1min…60min 与 range 月档 1mo/3mo/6mo 消歧、panes/style 作为 layers/theme 别名并互斥报错）与 astock/agent/chart_render.py（spec → Plotly Figure → div_id 固定的自包含 HTML，K 线 MA/BOLL/成交量与 macd/rsi/kdj 副图复用 astock/indicators，图注同屏 data_as_of + data_time 且缺任一时点写「时点未知」、默认 qfq 与 raw 口径注明、无 kaleido 时 png_path=None + degraded 并在 ToolResult.metadata 标注）。同时按冻结 DDL 落地 astock/agent/store.py（agent_runs/agent_steps/agent_artifacts 三表最小实现、内容寻址路径、digest 去重、artifact_id 可原样复现）与 astock/data.py 的唯一时点生产者 latest_bar_time。首版 CI 因 plotly 7.x 在 full_html 前置 <!doctype html> 而断言失败，已把断言改为同时接受 doctype 前缀并重跑 CI 通过。

## 需求对标

- `R-01` · ChartSpec 支持 candlestick/line/bar/scatter/heatmap/histogram（plan-20261107-005 验收 #1）
- `R-02` · 非法 spec 返回结构化错误（字段 + 原因），可回传模型重试（plan-20261107-005 验收 #2；ADR-016 C1）
- `R-03` · spec → Plotly HTML artifact，带 data_as_of/params/spec 元数据（plan-20261107-005 验收 #3；冻结清单 §3.4）
- `R-04` · K 线支持 MA/BOLL/成交量；口径复用 data/indicators（plan-20261107-005 验收 #4；ADR-016 C2）
- `R-05` · 图与数据快照可被回答引用（artifact_id）（plan-20261107-005 验收 #5；冻结清单 §5）
- `R-06` · ChartSpec v1 字段/枚举与《接口冻结清单》§3 逐字一致：version/kind/data/encode/transforms/panes/style/annotations；未知字段、非白名单 transform op 一律报错，不静默忽略（plan-20261107-005 验收 #6（ADR-016 C1，并入自 plan-20261110-005））
- `R-07` · 渲染只接受声明式 spec，禁止 exec/eval 任意 Python；交给模型的 schema 就是字段与枚举白名单（plan-20261107-005 验收 #7（ADR-016 C1））
- `R-08` · K 线默认 qfq；涨跌停/成交异常标的可切 raw，并在图注注明价格口径（plan-20261107-005 验收 #8（ADR-016 C2 + ADR-008））
- `R-09` · 每次渲染写 agent_artifacts 记录 {spec, params, data_as_of, data_time, source, code_version}，可凭 artifact_id 原样复现（plan-20261107-005 验收 #9（ADR-016 C3））
- `R-10` · 图与表同屏展示 data_as_of 与 data_time；无 kaleido 时降级为 HTML artifact 并在 ToolResult.metadata 标注 degraded（plan-20261107-005 验收 #10（ADR-016））
- `R-11` · period/range 词表消歧：分钟档只用 1min/5min/15min/30min/60min，月档只用 1mo/3mo/6mo；schema 用例分别断言 period=1min 取 1 分钟 bar、range=1mo 取 1 个月窗口，不得共用 1m（plan-20261107-005 验收 #11（ADR-016 C1））
- `R-12` · 声明式 ChartSpec（kind/title/data/encode/transforms/layers/annotations），手写校验（枚举、长度、白名单算子），v1 transforms 仅 filter/groupby/agg/sort/limit，统计图复用 backtest/factors/stats/track 既有输出（plan-20261107-005 描述；ADR-016 非目标）
- `R-13` · 渲染为 Plotly Figure → 自包含 HTML（gr.HTML）并可导出 PNG（kaleido 可选）（plan-20261107-005 描述）
- `R-14` · data_as_of/data_time 由唯一生产者 latest_bar_time(df, *, freq='D') 生成，工具与渲染器不得自行 strftime；日线 15:00、分钟档写 bar 结束时间（冻结清单 §6.2 / ADR-018 C1（plan-20261107-006 的消费前置））
