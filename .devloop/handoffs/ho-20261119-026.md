### 问题与建议

- P0 · 日/周/月线连续指标全部为空（MA/BOLL/MACD/RSI/KDJ 静默丢失）（open） — 建议：1) 只对分钟周期做连续竞价过滤：`indicator_frame = market.continuous_bars(transformed, freq=freq) if freq in MINUTE_FREQS else transformed`（日/周/月线全部是 close bar，应全部参与指标计算）；或让 `continuous_bars` 对非分钟频率返回全部行并同步调整 Q7 测试。2) 在 `_indicator_frame`/`_pane_series` 增加防御：当请求了 layers 但 indicator_frame 为空时写 warning，避免再次静默。3) 补数值断言而不只是图例名：对 daily/weekly/monthly 的 `layers=[{"type":"ma","window":20}]`，用 `indicators.sma(close,20)` 算出期望序列，断言渲染结果中 MA20 trace 的 y 与期望一致（至少尾部非 NaN）；保留现有 auction-only 分钟用例验证集合竞价被排除。修复后重跑 `pytest tests/test_agent_chart_render.py -q`。
- P1 · Agent 出图未关联真实 run，全部落成 source="render"、run_id=NULL（open） — 建议：在 runtime 与工具之间建立显式上下文：AgentRuntime 在 dispatch 前把当前 `run_id` 与 step 序号写入 `ToolContext`/`ContextVar`（或扩展 `registry.invoke` 签名），`_render_chart_payload` 从中取 `run_id`/`step` 并传给 `render_chart`；直接 UI 渲染不设置上下文，仍走 `source="render"`。补一个端到端测试：通过 AgentRuntime + 默认 registry 触发 chart 工具，断言 `agent_run_artifacts` 的 link 为 `(真实 run_id, "agent", step)`，且该 run 最终 status 由 runtime finish；另保留「无 run 的直接渲染 link.run_id 为 NULL」用例。
- P1 · 传入不存在的 run_id 时 chart_service 自建 running run 且成功后永不 finish（open） — 建议：chart_service 不应创建 run：若 `run_id` 非空但库中不存在，直接抛 `ValueError`/`ChartSpecError`（文案说明「run_id 必须由 runtime 先 ensure_run」），让 run 生命周期只归 runtime；成功渲染不得修改 run 状态。若确实要保留自动建 run 的兼容行为，则必须在 finally 中 finish，但这会把 Agent 的 run 提前结束，故推荐 fail-fast。同步修改 tests/test_agent_chart_render.py:581-602：改为预建 run 后测试 PNG 失败置 failed，并新增「传入不存在的 run_id 抛错且不新增 agent_runs 行」「成功后既有 run 仍为 running、由 runtime finish」两个用例。
- P2 · apply_transforms 末尾 return 后残留重复不可达代码（open） — 建议：删除 512-514 三行，只保留 509-511 的 attrs 赋值与 return；行为不变，无需新增测试，跑现有 `tests/test_agent_chart_render.py` 即可回归。
- P2 · load_chart_artifact 重算 meta_digest，无法校验记录 meta 是否被篡改（open） — 建议：给 `ArtifactRecord` 增加 `meta_digest: str` 字段，在 `_row_to_record` 中传 `version_row["meta_digest"]`；`load_chart_artifact` 改用 `record.meta_digest`，并断言 `meta_digest(record.meta) == record.meta_digest`，不一致抛 `ArtifactReplayUnavailable`（或至少追加高优先级 warning 并在 payload 标 `meta_verified=False`），不要静默用重算值。补一个测试：直接改库内 meta_json 后重新 `load_chart_artifact(..., mode="as_recorded")`，应检测到 meta_digest 不匹配；再补正常路径断言 payload.meta_digest 等于写入时的 digest。
- P2 · 图注把所有“视图时点未知”都归因为“聚合后无时间列”（open） — 建议：把原因显式传入 `_caption`（例如 `view_unknown_reason: Literal["aggregated","none","unknown"]`，由 render_figure 在 1549-1551 行判定）：只有确实因 transforms 丢掉时间列时才拼「（聚合后无时间列）」；`time_semantics=none` 用「视图时点未知（声明 none）」；其余用「视图时点未知」。补一个用例：artifact 记录 data_as_of、spec 声明 `time_semantics=none`、transforms 为空，断言图注不含「聚合后无时间列」；再保留一个聚合掉 trade_date 的用例断言包含该短语。
