### 问题与建议

- P1 · table_chart 的审计库 wiring 断裂：默认注册表不传 audit_db_path，自定义 db_path 时图表渲染必失败（open） — 建议：让 `build_default_registry(*, audit_db_path=None, artifact_root=None)` 透传 `build_file_registry(audit_db_path=..., artifact_root=...)`；AgentRuntime 先确定 `self.db_path` 再构建默认 registry（或显式把 `self.db_path` 作为 audit_db_path；db_path=None 时用临时/内存审计库，或明确禁止 table_chart 落默认库）。补一个 `AgentRuntime(db_path=tmp)` 调用 table_chart 的回归测试，断言 `agent_runs`/`agent_artifacts` 落在 tmp 库且 artifact 的 run link 正确；同时断言 db_path=None 时不会写 DEFAULT_DB_PATH。
- P1 · table_chart 用 CDN 渲染 HTML，偏离 ADR-016「自包含 HTML」决策，离线 artifact 会空白（open） — 建议：改为 `include_plotlyjs="inline"`（若担心 figure 过大，可在 ToolResult 中只回 artifact 句柄，UI 从 artifact 取完整 HTML，而不是降级为 CDN）；在 tests/test_agent_tools.py:604-651 增加断言 HTML 不含 `cdn.plot.ly` 外链，或至少覆盖一次无网络/离线渲染。若确需 CDN 例外，必须在 ADR-016 或接口冻结文档中记录理由、范围和离线降级方案，不能只留实现差异。
- P2 · CLI 只测了 --no-baseline 成功路径，缺 baseline 回归返回 1 的用例，CI gate 的失败路径无保护（open） — 建议：新增一个 CLI 失败路径用例：把 `.devloop/evals/agent_eval_baseline.json` 复制到 tmp，构造一个回归（例如把某 task 的 passed 改 false，或把 avg_steps 改大），调用 `main(["--tasks", ..., "--output", tmp, "--baseline", regressed])`，断言返回 1 且报告 comparison.ok 为 false；再补一个 baseline 与当前一致的返回 0 用例。测试只读 baseline 副本，不改受版本控制的文件。
