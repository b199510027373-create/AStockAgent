### 问题与建议

- P1 · 生产入口未传 db_path：AI 对话的 run 与工具调用都不落 agent_runs/agent_steps（AGENT-02 / ADR-017）（open） — 建议：给 build_agent_chat_tab 增加 db_path 形参并透传到 AgentChatController(db_path=...)（astock/agent_chat_ui.py:78-84 → astock/agent/chat.py:626），app.py:480 传 astock.agent.store.DEFAULT_DB_PATH（astock/agent/store.py:106，已支持 ASTOCK_DB_PATH 覆盖）。补一条用例：用 tmp_path 下的 sqlite 跑一次 controller.ask，断言 agent_runs 恰有 1 行 status 非 running、agent_steps 行数等于 len(result.steps)+1，或退一步断言 runtime_factory 收到的 AgentRuntime.db_path 非 None。若这项工作要留给 plan-20261107-008 统一接线，必须在本轮 handoff 写明并在 astock/agent_chat_ui.py:84 加显式 TODO+计划项号，不能以默认 None 静默上线。
- P1 · AC2–AC5 缺真机 UI 证据：流式刷新、iframe 渲染、引用跳转、中断按钮只测了纯函数（open） — 建议：合并前由开发在真实页面做一次手工冒烟并把证据写进 handoff tests（command 写启动方式 + evidence 写观察结果）：①上传 1 个 PDF + 1 个 Excel，看到「附件解析 2/2 成功」与页数/表名；②提问看步骤时间线先出、回答分段追加；③让助手出 K 线，确认 iframe 内图真的渲染、details 能展开 spec/来源；④点引用跳到 cite-N 卡片并显示正文摘录；⑤生成中点「⏹ 中断」：部分步骤保留、状态显示已中断，并立刻再问一句能正常进入「正在分析」；⑥无 key 时刷新页面看「模型未就绪」横幅 + 提问降级提示。模型不可用可用注入 FakeModel 的 controller，但第⑤步必须在浏览器里点按钮，而不是直接调 controller.interrupt()。
- P2 · 每个流式分片都重算引用卡片并同步读盘（glob 全部 meta.json + 整读正文），回答越长越卡（open） — 建议：在 respond() 里缓存上一次的 citations 指纹（如 tuple((c.label, c.page, c.sheet, c.file_id) for c in citations)）与对应 HTML，只在 step/done 帧或指纹变化时重算 answer 帧直接复用；同时给 render_citations_html 增加可选的 memo 字典参数，把 resolve_citation 结果按 (label, page, sheet) 缓存。改完后在 tests/test_agent_chat.py 补一条断言：连续两个相同 citations 的 answer 帧只发生一次 resolve（可用 monkeypatch 计数）。
- P2 · 中断在「新闻检索/建模型」阶段完全失效且提示误导，本地 cancel Event 是死参数（open） — 建议：把判定改成「self._busy.locked() 即视为已请求中断」并返回「⏹ 已请求中断…」，runtime 为 None 时也能生效；在 _ensure_runtime() 之后、启动 worker 之前检查 self._cancelled，若已置位就直接 yield done(_STOP_LABELS["interrupted"]) 并 return（finally 释放锁），不再启动 run。同时把 chat.py:728 的局部 cancel Event 挂到实例（如 self._cancel_event）并在 interrupt() 中 set 它，或直接删掉该形参，保持单一取消通道。
- P2 · 引用只匹配到工作表却显示「定位：…第 N 行/单元格」，精度被夸大且 note 为空（open） — 建议：当 citation.row 或 citation.cell 存在而匹配只到工作表时，把 note 设为「工作表级定位：未精确到第 N 行/单元格，先展示该工作表首段内容。」（复用 chat.py:525 的文案风格），或给 CitationDetail 增加 precise: bool 让 UI 在「定位：」后加「（工作表级）」小字。若行级定位留到后续计划项，本轮至少补齐这个 note，并在 tests/test_agent_chat.py 的 CitationTests 里加一条「row/cell 存在但只匹配到工作表 → note 含工作表面」的用例。
- P2 · 测试缺口：引用未命中退回首段、>20 条截断提示、并发发送 busy 分支均无用例（open） — 建议：补三条用例：①constructed Citation(page=999) 对已导入 CSV 调 resolve_citation，断言 found is True、snippet 等于首段、note 含「未在提取内容中精确命中」；②21 条 Citation 调 render_citations_html，断言含「还有 1 条引用未展示」且只渲染 20 个 details；③用可阻塞的 FakeRuntime（run 里先 sleep 或等 Event）对同一 AgentChatController 连续调用两次 ask()，断言第二次首个事件即 done 且 text 含「上一轮仍在生成」，第一次结束后的第三次 ask 能正常开始（顺带固定「_busy 已释放」这一不变量）。
