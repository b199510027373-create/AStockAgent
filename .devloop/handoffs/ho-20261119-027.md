- `R3` · chart_service 不得自建 run：run_id 不存在即 fail-fast，成功路径不改 run 状态，只有 PNG 硬失败才 fail_run；补三个生命周期用例（rev-20261119-002 / iss-mwnlpll3-c475bb (P1)）
- `R4` · 删除 apply_transforms return 之后重复 attrs 赋值死代码（rev-20261119-002 / iss-mwnlpnd5-4be737 (P2)）
- `R5` · 回放必须校验库内 meta_digest：ArtifactRecord 增 meta_digest，load_chart_artifact 用记录值比对，不一致抛 ArtifactReplayUnavailable；补篡改与被篡改两个用例（rev-20261119-002 / iss-mwnlppp6-b47e47 (P2)）

- `R7` · 补齐数值级与端到端测试：日/周/月指标数值对照、agent runtime→tool artifact link 端到端；不得只断言图例文字（评审 handoff ho-20261119-026（测试充分性））
