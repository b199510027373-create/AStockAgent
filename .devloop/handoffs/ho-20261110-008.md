# 交付文档：「无显著 alpha」实时横幅（ledger 驱动）— 初始交付

> 开发会话 · initial · 2026-11-10T07:37:07.095Z

## 摘要

推荐页顶部现在是 ledger 驱动的实时显著性横幅：每次渲染从 SQLite tracking 表读实盘（source=live）T+5 超额，按推荐日聚合 Top2 与其余的超额均值差，经 stats.newey_west（lag=4、Student-t）得到 p；有效独立样本 <10 时 p 强制为 None 并显示「样本不足，不显示显著性」。UI 只消费 use_cases.run_alpha_banner() 返回的 Markdown，不实现统计。当前真实 data/astock.db 只有 3 个实盘交易日 → insufficient 灰底、无 p；种子 60 天冒烟 → positive 绿底、独立窗口 12、p<0.0001。PR #5 已开，CI run 42775574149 success，等待人工评审/合并。

## 需求对标

- `R1` · 顶部灰底横幅实时显示「实盘样本 N 个交易日、独立窗口≈K、Top2−其余 p=…」，数字从 ledger 聚合、经 stats.py 计算（plan-20261103-005 描述 / m00001）
- `R2` · 横幅数字来自 ledger/stats 实时聚合，而非硬编码（验收标准 1）
- `R3` · 展示实盘样本数、有效独立窗口、Top2−其余 p（或「样本不足，暂不显示」）（验收标准 2）
- `R4` · 样本达到门槛后横幅自动消失或转为正向提示（验收标准 3）
- `R5` · 无可信统计时不得显示任何显著性结论（验收标准 4）
- `R6` · p 值只允许来自 astock/stats.py；*_ui.py 只装配，不实现统计；领域层不依赖 UI（契约 STAT-01 / ARCH-01 / ARCH-02，ADR-006）
