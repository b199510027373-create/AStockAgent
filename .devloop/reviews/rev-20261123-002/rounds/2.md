## 本轮问题

### P1 · table_chart 的审计库 wiring 断裂：默认注册表不传 audit_db_path，自定义 db_path 时图表渲染必失败

- 位置：`astock/agent/runtime.py:97-110,242-252`
- 状态：未闭环
- 置信度：0.9

**证据**

`build_default_registry()`（runtime.py:97-110）只调用 `register_market_tools(build_file_registry())`，没有把 `audit_db_path`/`artifact_root` 传下去；`AgentRuntime.__init__` 在 runtime.py:242 先用 `_default_registry()` 建注册表，:252 才设置 `self.db_path`。file_tools.py:663-673 的 table_chart 把 `audit_db_path`（默认 None）传给 chart_service.render_chart；chart_service.py:105-107 在 db_path=None 时 `connect(None)` 到 DEFAULT_DB_PATH，:117-125 又要求 run_id 必须存在于该库的 agent_runs。因此 `AgentRuntime(db_path=tmp/audit.db)` + 默认注册表调用 table_chart 时，run 在 tmp 库、render_chart 查默认 data/astock.db，直接抛 `ValueError: run_id=... 不存在`；而 db_path=None 时又会把 artifact/审计写到默认库，违反 runtime.py:250-251 的“测试与纯内存调用无副作用”。tests/test_agent_tools.py:604-651 只直接调用带 audit_db_path 的 build_file_registry，未覆盖 AgentRuntime 自定义 db_path，所以该断裂未被测试发现。

**建议**

让 `build_default_registry(*, audit_db_path=None, artifact_root=None)` 透传 `build_file_registry(audit_db_path=..., artifact_root=...)`；AgentRuntime 先确定 `self.db_path` 再构建默认 registry（或显式把 `self.db_path` 作为 audit_db_path；db_path=None 时用临时/内存审计库，或明确禁止 table_chart 落默认库）。补一个 `AgentRuntime(db_path=tmp)` 调用 table_chart 的回归测试，断言 `agent_runs`/`agent_artifacts` 落在 tmp 库且 artifact 的 run link 正确；同时断言 db_path=None 时不会写 DEFAULT_DB_PATH。

### P1 · table_chart 用 CDN 渲染 HTML，偏离 ADR-016「自包含 HTML」决策，离线 artifact 会空白

- 位置：`astock/agent/tools/file_tools.py:663-673`
- 状态：未闭环
- 置信度：0.85

**证据**

file_tools.py:671 显式传入 `include_plotlyjs="cdn"`；ADR-016 决策 3（.devloop/architecture/adr/ADR-016-chart-spec.md:32）要求 spec → Plotly Figure → 自包含 HTML，chart_render.py:1 与 :1520 也自述“自包含 HTML”，chart_service.render_chart 默认值为 `include_plotlyjs: str | bool = "inline"`（chart_service.py:91）。tests/test_agent_tools.py:641-643 只断言 `"<html" in result.figure.lower()`，不检查外部脚本，因此测试无法发现离线打开 artifact/UI 时 Plotly 不加载、图表空白。该偏差只出现在新 table_chart 路径，市场图表未受影响。

**建议**

改为 `include_plotlyjs="inline"`（若担心 figure 过大，可在 ToolResult 中只回 artifact 句柄，UI 从 artifact 取完整 HTML，而不是降级为 CDN）；在 tests/test_agent_tools.py:604-651 增加断言 HTML 不含 `cdn.plot.ly` 外链，或至少覆盖一次无网络/离线渲染。若确需 CDN 例外，必须在 ADR-016 或接口冻结文档中记录理由、范围和离线降级方案，不能只留实现差异。
